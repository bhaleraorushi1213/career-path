# 🎯 JobTrackr - Job Application Tracker

A modern, intuitive Kanban-style job application tracker built with Next.js 16, helping you organize and manage your job search efficiently.

Career Path Live Demo -> (https://via.placeholder.com/1200x400/1e2a38/d9a441?text=JobTrackr+-+Track+Your+Dream+Jobs)

## 🌟 Features

### 📊 Kanban Board
- **Drag & Drop Interface**: Seamlessly move job applications between stages
- **5 Default Columns**: Wishlist → Applied → Interview → Offer → Rejected
- **Visual Organization**: Color-coded columns for quick status recognition

### 💼 Job Application Management
- **Comprehensive Details**: Track company, position, location, salary, and more
- **Custom Tags**: Organize applications with personalized tags
- **Notes & Descriptions**: Store job descriptions and personal notes
- **URL Tracking**: Save direct links to job postings

### 🎨 Modern UI/UX
- **Dark Theme**: Easy on the eyes with a professional dark color scheme
- **Smooth Animations**: Powered by Framer Motion for delightful interactions
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Slide-over Panels**: Elegant detail views and edit forms

### ⚡ Performance
- **Server Components**: Lightning-fast page loads with Next.js 16
- **Optimistic Updates**: Instant UI feedback while saving to database
- **Smart Caching**: Efficient data fetching with cache tags

## 🛠️ Tech Stack

- **Framework**: [Next.js 16.2.9](https://nextjs.org/)
- **Database**: [MongoDB](https://www.mongodb.com/) with Mongoose ODM
- **Authentication**: Custom auth with session management
- **UI Components**: Custom components with Tailwind CSS
- **Drag & Drop**: [@dnd-kit](https://dndkit.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
